# Indicadores Farmacia MVP

**Parceiro:** Sabará Hospital Infantil
**Problema:** Consolidação manual de planilhas de indicadores da farmácia clínica, gerando retrabalho e atrasos.
**Solução:** MVP para automatizar o registro e o cálculo de três indicadores prioritários.

## Tecnologias
* Python (3.14)
* Flask
* SQLite
* WTForms
* pytest


## Como executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute a aplicação: `python app.py`
